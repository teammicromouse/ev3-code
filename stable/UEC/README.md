# **UEC** | **Ultra Efficient** Code

UEC is our next generation of code files, designed for speed, efficiency, and reliability. It replaces the older PIN series. UEC strips out most elements and retains what is necessary, plus a streamlined user experience to focus on the things that matter most.

# ev3-code

> [!NOTE]
> Due to the difficulty of using source controlled Git with EV3 binaries, most updates are tracked via GitHub releases and a file naming scheme.

`teammicromouse/ev3-code` is the complete source code archives for our robot code. Unfortunately, most of the commit messages are stale and are not descriptive (as this was a time when we used to edit one master copy of a file with no version history).

Refer to the `stable/UEC` folder for the latest updated copies or `stable/PIN` for an archive of previous generation working code. Note that any files found elsewhere should be considered to be unstable, including in the `stable` folder but not in PIN NG or in UEC.
